# Xumuid Mod - GTA San Andreas The Definitive Edition (v3.0)

Mod Chaos & Menu Konfigurasi Resmi untuk Grand Theft Auto: San Andreas The Definitive Edition.

## 📦 Isi File
- **`xumuid mod.exe`**: Aplikasi pengatur tombol, aktivasi lisensi resmi, dan penguji efek langsung ke game.
- **`xumuid mod[fs].js`**: Script engine mod CLEO Redux berproteksi tinggi dengan puluhan cheat chaos & superpower lengkap siap pakai.
- **`xumuid_config.ini`**: Konfigurasi tombol dan status lisensi.
- **`PANDUAN_PEMASANGAN.txt`**: Panduan lengkap pemasangan & aktivasi.

## 🚀 Cara Pemasangan
1. Salin semua file dari repositori ini ke folder `CLEO` game GTA San Andreas Definitive Edition kamu:
   ```
   C:\Games\Grand Theft Auto San Andreas The Definitive Edition\Gameface\Binaries\Win64\CLEO\
   ```
2. Jalankan `xumuid mod.exe` saat PC terhubung internet untuk aktivasi lisensi pertama kali.
3. Masukkan Kunci Lisensi resmi milikmu (format: `XUM-XXXX-XXXX-XXXX`), lalu klik **Aktifkan Lisensi**.
4. Setelah aktif, mod dapat dimainkan **100% Offline** selamanya.
